# danikh.design

Portfolio of Danikh Nizam. Plain HTML/CSS/JS generated by a small Python script, so there is no framework to maintain.

## How it's organised

- `content/` holds one text file per project, such as `content/minda.txt`. The format is documented at the top of `build.py`.
- `media/` holds the web-sized images and videos the site uses.
- `originals/` holds full-size source files. It isn't committed to git or deployed.
- `src/` holds the stylesheet, script and Switzer font files.
- `build.py` writes the finished site into `dist/`.

## Adding or changing a project

1. Put new images or videos in `originals/` and run `python3 optimize.py`. This makes compressed copies in `media/`, and GIFs become small looping videos.
2. Edit or add a file in `content/`. To add a project to the home page or Work page, add its slug to `HOME_ORDER` or `WORK_ORDER` in `build.py`.
3. Run `python3 build.py`, then open `dist/index.html` to check it.
4. Push to GitHub. Vercel rebuilds and deploys automatically.

## Hosting

Vercel builds the site with `python3 build.py` and serves `dist/` (see `vercel.json`). The custom domain, danikh.design, is set under Vercel → Project → Settings → Domains.

## PATH project page
- `media/demos/path-archive/` is a copy of the PATH-Archive repo and `media/demos/path-website/` is a copy of the MFS-Website repo. They load on the PATH page only when a visitor clicks the button.
- The copy of the MFS website has a small fixed label added before `</body>` ("Speculative design fiction · Not a real government website"), and the archive's "Visit the MFS website" link points to that labelled copy. Keep both if you refresh these folders from the repos.
- The 3D worldbuilding model is not copied; the page links to https://nikhoftime.github.io/PATH-Worldbuilding/.
